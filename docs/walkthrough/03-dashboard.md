# Dashboard'u aç

Tek karnede:

- **Maliyet** — gün/model/ajan kırılımı, bütçe uyarıları (abonelikte "fatura" değil, çıkardığın değer)
- **Farm Status kartı** — hangi alt sistem canlı, hangisi hiç kullanılmamış; uyuyan her satırın yanında **tek tık uyandırma** düğmesi
- **Ajan karşılaştırması** — oturum, hata oranı, kalite, cache verimi
- **En pahalı oturumlar** — tıkla → oturum görüntüleyici

Farm Status kartı dürüsttür: görev kuyruğunu hiç kullanmadıysan "never used" der ve örnek kurulumu önerir.
