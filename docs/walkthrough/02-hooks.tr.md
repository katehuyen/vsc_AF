# Canlı hook'ları kur

**Install Live Hooks**, Claude Code ayarlarına küçük hook komutları ekler. Her olay (komut, araç çağrısı, izin bekleme, tur sonu) `127.0.0.1`'deki yerel dinleyiciye POST edilir — **hiçbir veri makineden çıkmaz.**

Bununla çalışanlar:

- **Live Timeline** — ajan başına kulvar, gerçek zamanlı
- **Sıra-sende bildirimleri** — ajan girdini beklemeye geçince ses/odak/uyarı
- **Takılma ve izin uyarıları** — durum çubuğu sarıya döner

> Önemli: hook'lar oturum açılışında okunur — kurulumdan sonra **açık claude oturumlarını yeniden başlat**.
