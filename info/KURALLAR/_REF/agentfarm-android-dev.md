# Agent Farm Android Companion — Development Rules

Binding on **whichever agent** works in `D:\zone\dev\git\miropharm\and_AgentFarm` (the Android companion of Agent Farm, vault project `PRS.MuratVural_DEV_AND.AgentFarm`). The universal rules apply as everywhere (`_REF/engineering.md`, `_REF/test-discipline.md`, `_REF/ui-conventions.md`, `_REF/git.md` A); this file holds only what is specific to this repo and its bond with Agent Farm.

1. **Read before changing code:** the repo's `docs/CONVENTIONS.md` (its layers, the phone's instrument for each design name, its gates) and the vault SOP `10_Notes/A-SOP - Android Otonom Geliştirme ve Test Çalışma Yöntemi - 260930.md` (the cloud dev/test loop and the completion list).
2. **Cloud only.** Never build, install tools, emulate, or inspect installed tools on the user's PC. GitHub Actions builds and runs the emulator; commit markers `[testlab]` (Firebase Test Lab) and `[deliver]` (App Distribution to the user's phone). Local work = editing + the node repo gate.
3. **Narrate and ask for accounts.** Write in chat what you do and why before each step; accounts, keys, billing, services and publishing are the user's — ask, do not choose.
4. **Done** = the commit's CI run green + its screenshots looked at (emulator artifacts: portrait, landscape, dark, `screen-state.txt`). A commit made before that proof names the pending run in `Verification:`; the result goes to `docs/test-plan.md` and the worklog.
5. **Record.** The counter started at `v1.13`. A release bumps `appVersion` (`app/build.gradle.kts`) and adds a Turkish `CHANGELOG.md` entry — the phone's release notes are read from it (`scripts/ci/deliver.sh`).
6. **Cross-repo parity.** The phone shows Agent Farm's own pages, served by `vsc_AgentFarm/src/remote/`; it never re-implements a screen. A native entry (notification action, share, voice, widget) calls existing bridge ops; a missing capability is added in `vsc_AgentFarm` under `_REF/agentfarm-dev.md` in the same work item. A native "new session" uses the Telegram `/new` launch verdict (`seedLastLaunch`), not `sessions.start`. The shell↔host contract is owned by `vsc_AgentFarm/src/remote/contract`; this repo carries its versioned copy in `contract/`, refreshed in the same work item, and `docs/PROTOKOL-VE-MIMARI.md` describes it.
7. **The repo is public.** No key, keystore password other than the committed debug key, or tester email goes into a tracked file; `docs/Keys/` stays ignored.
8. **Design of record:** vault project `10_Notes/A-PLN - Android Uygulaması Yeniden Tasarım Raporu - Telefondan Tam Agent Farm - 260930.md` (hybrid shell, security, flexibility, review refinements).
