# Icon and Wording Discipline

- A task is **"cancelled"**, never "killed". Unpleasant icons (⚰️ and the like) are forbidden.
- The icon set is fixed by the user and written in the LifeOS document: ⏬ Incoming · ⏩ Active · 🔀 In progress · ⏸️ Waiting · 🅿️ Parked · 💡 Idea · ✅ Done · ❌ Cancelled · ⏪ Interruption · 🟢🟡🔴 mode. This set is **never changed**; do not invent your own (neither cartoon emoji 🔥🌊📥🪂 nor colorless geometric marks ○◐◷⚑).
- ⛔ is **only** for the Obsidian Tasks dependency field; never use it as a status icon.
- **Icons, Obsidian Tasks metadata (🆔 ⛔ ⏫ 📅), names, and formats the user set by hand are never changed** — ask first if you need to.
