# Open the Dashboard

On a single scorecard:

- **Cost** — day/model/agent breakdown, budget alerts (on a subscription it's not a "bill" but the value you extracted)
- **Farm Status card** — which subsystem is live, which was never used; a **one-click wake-up** button next to each dormant row
- **Agent comparison** — session, error rate, quality, cache efficiency
- **Most expensive sessions** — click → the session viewer

The Farm Status card is honest: if you've never used the task queue it says "never used" and suggests setting up an example.
