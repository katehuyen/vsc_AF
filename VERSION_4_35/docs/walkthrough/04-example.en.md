# Set up your first automation

**Set Up Example Automation** sets up one of three ready examples as a real, editable definition:

| Example | What it does |
| --- | --- |
| 📥 **Inbox duty** | When a file lands in a folder you pick, the agent reviews and triages it (watch trigger) |
| 🌅 **Morning briefing** | Every day at 09:00 the agent writes a short day plan (daily schedule) |
| 🔗 **Two-agent chain** | A analyzes → its output flows to B via `{prev_text}` → B summarizes (workflow) |

They all show up in the **Tasks** view; edit, disable or delete them from there. What's set up isn't magic, it's a normal definition you could also set up by hand — the example is there to get past the blank-page problem.
